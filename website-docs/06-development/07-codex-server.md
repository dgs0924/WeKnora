# 服务器 Codex 个人连接

通过官方 Codex app-server 的 stdio 协议使用服务器上已经登录的 Codex。
它与「Continue with ChatGPT」的 SIWC 凭据、模型目录分别管理，不把 Codex 的
`auth.json` 转换为 API Key，也不通过非官方推理网关转发令牌。

此入口默认只对连接所有者开放。连接所有者同时具有系统管理员权限时，可以为
全系统的有效用户逐一授权指定模型；授权随用户跨空间生效，但不会授予原空间
的知识库、会话或管理权限。API Key 调用者及没有原始用户身份的后台任务仍被拒绝。

应用内授权不代表供应商套餐许可的扩展。多人使用前仍需确认相应接入资格，
不要将个人登录部署成公共或商业托管推理服务。
Codex 官方集成及适用范围见 [App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## 登录与绑定

1. 在服务器安装官方 Codex CLI，使用普通用户执行 `codex login --device-auth`。
   在浏览器打开 CLI 提供的地址，亲自输入设备码并完成授权，不需要回调端口转发。
2. 使用 `codex login status` 验证登录。凭据目录权限设为 `0700`，文件为 `0600`。
   不把文件内容写进日志、聊天、源码或镜像。
3. 取得要使用套餐的 WeKnora 用户 ID，由部署管理员设置以下变量。
4. 重建包含此功能的个人 fork 镜像，加载 `docker-compose.codex.yml` 后重建 app 容器。
5. 使用绑定的用户登录，进入「设置 → ChatGPT → 服务器 Codex 账号」，刷新模型并启用。

| 变量 | 说明 |
| --- | --- |
| `WEKNORA_CODEX_OWNER_USER_ID` | 连接所有者的 WeKnora 用户 ID；未设置时关闭入口；只有本人且为系统管理员时可管理授权 |
| `WEKNORA_CODEX_BINARY` | 后端可执行的官方 Codex 二进制绝对路径 |
| `WEKNORA_CODEX_HOME` | Codex 自己管理和续期的凭据目录 |
| `WEKNORA_CODEX_WORKDIR` | 隔离的空工作目录，不应挂载业务源码或宿主根目录 |
| `CODEX_HOST_VENDOR_DIR` | Compose 覆盖文件使用的宿主目录，包含 `bin/codex` |
| `CODEX_HOST_HOME` | Compose 覆盖文件使用的宿主 Codex 登录目录 |

容器内执行用户必须能访问凭据目录。当前 app 镜像的 `appuser` 为 UID/GID 1000；
不要为解决权限问题把凭据改为全员可读。凭据挂载需要可写，以便 Codex 自动续期。
二进制目录只读挂载，工作目录使用临时文件系统。

## 从模型管理启用

在「模型管理 → 添加模型」将模型来源切换为「账号授权」，再选择授权渠道：

- ChatGPT（个人账号）：使用当前用户绑定的 ChatGPT 账号，支持对话和视觉模型。
- ChatGPT（服务器账号）：使用服务器 Codex 账号，支持目录中声明图片输入能力的对话和视觉模型。

两种渠道均不再列于 API 服务商下拉中，也不需要填写服务商 URL 或 API Key。
选择模型后使用对应的专用启用接口，已启用模型会复用原记录。已有账号绑定、
模型和用户授权不会因界面分类调整而迁移或修改。

「账号授权」作为通用来源入口，暂不支持 Embedding、ReRank 和语音类型。
获授权用户直接在模型选择器使用已分配的服务器模型，不能通过添加入口自行
扩大发放权限。

## 按用户授权

1. 所有者进入「设置 → ChatGPT → 服务器 Codex 账号 → 用户模型授权」。
2. 选择一个有效用户，勾选允许使用的已启用模型，保存。
3. 对方在有权访问的空间中，可从常规模型选择器看到并使用获授权模型。
4. 清空该用户的勾选并保存，即撤销其全部 Codex 模型授权；其他用户不受影响。

每次保存是用户维度的数据库事务，任一模型无效时不会部分生效。授权存放在
独立的 `codex_model_grants` 表，不保存在用户可提交的模型参数里。旧模型 ID
和空间归属保持不变；普通模型的空间隔离不变。

撤销后，新请求与仍在排队的请求会被拒绝；已开始的生成不会被强制中断。
用户或连接所有者停用后，也不能继续使用授权。授权管理不依赖 CLI 当前是否在线，
即使连接异常也能撤销。变更连接所有者不会继承旧所有者发放的权限。

升级会应用 PostgreSQL `000116` / SQLite `000036` 迁移，创建空的授权表，
不会自动授权任何用户。数据库降级会删除该表，降级前应备份授权记录。

## 套餐用量

服务器账号页通过官方 `account/rateLimits/read` 获取当前用量快照，显示实际返回的
计费窗口、已用和剩余百分比以及本地时区的重置时间。数据是整个服务器 Codex
账号的共享用量，不是 WeKnora 独占用量，也不是按被授权用户统计。

只有连接所有者可读取 `/api/v1/codex/usage`；授予模型权限不会授予读取账号用量的
权限。进入已连接账号页或手动刷新时读取，无自动轮询。读取失败或上游未返回
有效百分比时显示暂不可用，不把缺失数据当作零用量。此接口不消费额度重置次数。

接口来源：[Codex App Server 用量窗口](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)。

## 调用边界

- 支持对话和视觉模型；视觉目录只列出官方声明支持图片输入的型号。Embedding、ReRank 和语音不通过此入口提供。
- 同名对话与视觉模型使用独立记录及授权；启用视觉模型不会修改原有对话记录，也不会自动授权其他用户。
- 视觉调用传入图片字节，由服务端编码为内嵌图片；拒绝任意本地路径和远程图片地址，最多 20 张、单张 20 MiB、合计 50 MiB。
- 由 Codex 维护登录状态；退出服务器 Codex 后，此连接也会不可用。
- 每次请求验证真实用户身份与最新授权，排队结束后再检查一次；审计身份仍是
  实际调用者，不会替换成连接所有者。模型及授权记录不包含访问或刷新令牌。
- Codex 子进程只处理模型对话，不授予其执行服务器命令或直接访问业务文件的能力。
- 服务器需要能访问 OpenAI。若使用代理，设置后端的 `HTTPS_PROXY`、`HTTP_PROXY`
  及正确的 `NO_PROXY`；容器的 `127.0.0.1` 不等于宿主机。
- 模型目录不等于套餐额度保证，以真实请求完成状态为准。

官方设备码登录说明：[无桌面设备登录](https://learn.chatgpt.com/docs/auth#login-on-headless-devices)。

## Wiki 后台任务与恢复

Wiki 的文档入库、撤回、页面合并和索引收尾都会保存并恢复真实发起人身份。
同一知识库中不同用户的任务分批处理，不共享个人账号的模型调用或请求缓存。
知识库的「图谱」视图展示 Wiki 页面之间的链接，随 Wiki 页面生成更新。

升级前缺少身份的任务不会自动继承模型所有者或管理员权限。知识库管理者可在
Wiki 或图谱页面点击「恢复生成」，确认以当前网页登录账号恢复旧任务。该操作
会校验当前账号的知识库和模型权限、记录审计，只接管尚未领取且缺少身份的操作；
同时为已完成但尚无 Wiki 来源页面的文档补排生成任务，复用现有分块。重复点击不会重复入队，
不会重新解析文档、修改 Embedding 或增加文档的待完成任务计数。
